# CCS Lite 0.2.21

发布日期：2026-11-23。此版本将 0.2.20 与 0.2.21 各轮候选中的改动整理为正式版。

## 新增功能

- 供应商编码兼容性检查覆盖 SSE、工具调用及结果回传、响应上下文和隔离的小型开发任务。普通聊天可用与开发任务通过分别展示，不要求安装真实客户端。
- 可查看逐轮请求和工具执行证据、分页历史报告，并导出脱敏 JSON。CCOK 与编码检查调用统一计入“探测统计”。
- 请求详情保存当时的候选、排除原因、实际尝试和流式失败阶段，关联恢复确认、绑定迁移和能力报告。
- 提供安装自检与隔离可靠性演练入口：`npm run doctor`、`npm run drill`。

## 修复和界面调整

- 修复新增供应商优先级未按输入保存、删除后列表未及时更新。
- 活动请求显示客户端传入的 Codex 对话 ID，并区分请求 ID。
- 统一分组、设置、添加供应商、统计和价格实验的地址；直接打开、刷新和浏览器历史恢复对应页面与分组。
- 顶部八张指标卡收窄；流式诊断使用浮层，展开不会改变顶部布局。计数、时间和延迟带单位，并说明统计范围。
- 管理台提供操作通知，修复侧栏分组名称居中。

## 会话级升级

前置器保持公开端口。会话正在处理的请求仍由原工作进程完成；网络响应与上下文完成检查点均确认后，该会话的后续请求进入新版本。

旧版本退役仅检查自身的转发、会话和待确认上下文。默认持续空闲至少 5 秒，且新版本已通过连续健康观察，才正常停止旧进程；新版本有活动请求不会再阻止旧版本退出，也不会阻止之后的下一轮升级。

从旧前置器升级需要在空闲窗口重启一次前置器；只升级工作进程不会加载新的退役规则。修复生效后，协议兼容的工作进程仍可在线 `upgrade-session`。固定回退目录不能在仍被引用时删除。

## 数据与运行边界

运行数据留在本机，发布仓库和代码包不包含真实供应商密钥、配置、对话或业务日志。用量、配置事务和上下文继续经前置器协调持久化。请求证据不补造旧日志未记录的信息。

已经向客户端输出的 SSE 不会拼接另一供应商响应；输出前故障转移仍取决于错误可重试且存在可用候选。编码检查结果仅证明该供应商在指定模型、配置与任务下的表现。

最低 Node.js 版本仍为 18.17，支持范围没有扩展到 Node.js 16。建议使用受维护的 Node.js LTS。

## 发布验收

本机 macOS arm64、Node.js 18.20.8 已完成：264 项单元测试、94 项集成场景（其中一次快照因测试期间锁文件更新被拒绝，文件稳定后该项单独重跑通过）、浏览器页面与路由验收、源码模式交接和仅运行依赖的干净安装。测试使用独立目录、随机端口和模拟供应商，不修改生产数据。远程 Linux/Node.js 22 与 macOS/Node.js 24 的结果以本版本 GitHub Actions 为准。
